Cultivation Idle

An idle game about becoming immortal.

Run timed cultivation sessions to gather qi, break through the stages of five realms, and study techniques for permanent stats. Build an Abode for alchemy and artifacts, fight through twelve Regions for materials, then reincarnate and spend what you earned on the Samsara tree.

Every fight, tribulation and breakthrough gate is derived by balance tooling rather than tuned by hand, so a change to the numbers re-derives the obstacles.

JP Subs

English subtitles for Japanese YouTube, translated locally.

The extension reads a video's Japanese caption track, translates it with a local LLM through Ollama, and draws the result over the player. Nothing is uploaded, there is no API key, and it costs nothing per video.

It's aimed at what YouTube's own auto-translate handles worst, like VTuber archives and anime. A first pass reads the whole transcript to work out who's speaking and which names recur, and a per-channel glossary keeps those names consistent from one video to the next.

~28×faster than real time
17 minfor an 8-hour archive
$0per video, no API key

Whisper Subtitler

English subtitles for any Japanese video or audio file, made locally.

Drop a file in and get .srt subtitles beside it. It covers what JP Subs can't: local recordings, Niconico and Bilibili downloads and stream archives that have no caption track. Nothing is uploaded and there is no API key.

faster-whisper (large-v3) transcribes the speech, then the two-pass Ollama pipeline ported from JP Subs translates it, with a per-series glossary to keep names consistent. Progress is saved as it goes, so a long archive can be paused and resumed.

~10 minper hour of speech
$0per file, no API key
3outputs: EN, JA, bilingual

Solar System

A real-time solar system in C++ and modern OpenGL.

Built from scratch for a university graphics module. The planets, moon and comet are procedurally generated, the comet follows a Bézier curve, and every lit body gets a shadow map rendered from the sun's direction.

The scene renders in HDR with bloom, with a cubemap skybox, a glowing sun and particle effects for the comet trail and the UFO's exhaust. Switch between a planet, moon, comet or a flyable UFO camera.

6 + 1planets, plus the Moon
4096²shadow map resolution
4camera modes
